# Python Scientific Calculator

A graphical scientific calculator built with **Python** and **Tkinter**.

## Features

- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Scientific functions:
  - Sine (sin)
  - Cosine (cos)
  - Tangent (tan)
  - Logarithm (log)
  - Square Root (√)
- Graphical User Interface (GUI) built with Tkinter
- Custom-designed buttons using PNG images

## Technologies Used

- Python
- Tkinter
- PNG Images

## Installation & Usage

1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Run the main Python file:

```bash
python "1. Calculator Final.py"
```

## Project Structure

- `1. Calculator Final.py` – Main application file
- `*.png` – Image assets used for calculator buttons
